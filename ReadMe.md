# Moji zapiski

Zbirka študijskih in drugih zapiskov, napisanih v [Obsidianu](https://obsidian.md) v Markdownu (po potrebi z LaTeX formulami). Jezik: slovenščina.

## Teme

- **Matematika:** matematična indukcija, števila (N, Z, Q, R), intervali, ulomki in odstotki, Fibonaccijevo zaporedje
- **Obsidian:** bližnjice, snippeti za Latex Suite in pregled Markdown sintakse

Seznam dopolnjujem sproti, ko dodam nove teme.

## Kako brati

Najlepši izris dobiš v Obsidianu:

1. Kloniraj repozitorij: `git clone https://github.com/UPORABNIK/REPO.git`
2. V Obsidianu izberi *Open folder as vault* in izberi kloniran direktorij.
3. Formule se izrišejo brez dodatnih nastavitev.

Zapiske lahko pregledaš tudi neposredno na GitHubu. Večina vsebine se tam izriše, Obsidianove posebnosti (povezave `[[ ]]`, okvirji) pa se prikažejo drugače, kot so mišljene.

## Uporabljeni vtičniki

- **Latex Suite:** hitro pisanje formul s snippeti
- **Calctex:** samodejni izračun formul
- **Git:** verzioniranje zapiskov

## Opomba

Zapiski so za učenje in lahko vsebujejo napake. Če kakšno opaziš, odpri issue.
